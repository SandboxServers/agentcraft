# MP-02 Worknote: build at an offset

> Packet: MP-02 (Build at an offset). Branch: `mp/MP-02-offset-build`. Base: `mp/integration`.
> Status: Review. Written by a worker, reviewed by the coordinator (one fix round, then small corrections by the coordinator), verified outside the worker's sandbox.

## Contract

- **Goal:** Apply-time translation of the HQ `Plan` and per-plot `PlanStore` files; `StudioHqBuilder` passes `options.origin()` to `Plan` and `Anchors.Builder` without geometry edits. Telemetry `plot_built` / `plot_build_failed` only for studios other than `LOCAL`, with `studio` and `plot` correlators.
- **Decisions followed:** plot index from `Plots.directory().plotOf(studio)`; x/z 16-aligned (`bad_origin`); y translated as given; legacy `invalidateUnless(server, builder)` unchanged for `LOCAL`; per-plot `invalidateUnless(server, studio, builder)` added for MP-03; game tests use `Plots.install` on plots 1 to 4 and never force-rebuild plot 0.

## What shipped

| File | Behavior |

| `mod/src/gametest/java/dev/agentcraft/gametest/mp/offset/BuildAtOffsetTest.java` | Nine game tests (see below). |

### Telemetry (non-`LOCAL` only)

- `plot_built`: `studio=<owner UUID> plot=<index> ms=<whole build> changed=<cells+connections> kept=<kept>`
- `plot_build_failed`: `studio=<owner UUID>`; `plot=<index>` when `plotOf(studio)` is present; `reason=` one of `no_plot`, `bad_origin`, `io_error`, `build_error`

`build_error` is logged by the outer `catch` on any `RuntimeException` after refusal; there is no practical game-test trigger (would require a thrown failure mid-build).

## APIs for later packets

- **`PlanStore.invalidateUnless(MinecraftServer server, StudioId studio, String builder)`**: when MP-02 and MP-03 meet on the integration branch, `HqFeature.buildAndPublish` (`HqFeature.java:104`) must change from `invalidateUnless(server, builder.id())` to `invalidateUnless(server, options.studio(), builder.id())`, so that a player's own plan file is the one invalidated. MP-03 was written before this method existed, so that one-line change is still owed.
- **`PlanStore.load` / `save(server, studio, …)`** — Non-`LOCAL` builds must use the studio-aware forms; path uses directory index only; `save` creates `agentcraft/plots/<index>/`.
- **`StudioHqBuilder.build`** — Non-`LOCAL` requires a registered `Plot` with matching `origin()`; publish with `Anchors.publish(studio, anchors.build())`.

## Deviations

- **`LOCAL` only at `BlockPos.ZERO`:** The packet text does not state this, but the legacy `agentcraft-hq-plan.dat` stores no origin. A `LOCAL` build at another 16-aligned offset would load plot 0's history and keep every cell as "player-changed". Refusal uses `bad_origin` (same as misaligned x/z for telemetry grouping).

## Game tests (`BuildAtOffsetTest`)

| Test | Proves |
|---|---|
| `offsetBuildLeavesTwoBlockShellUntouched` | Every cell in the 2-block shell around the translated site box is unchanged by a build. The test has a plot of its own (plot 4), so in any test order this is that plot's first build and really writes the studio; it asserts `changed` is not 0. |
| `forceBuildAtPlotOneDoesNotWriteUntranslatedPlotZero` | A marker block in plot 0 survives a forced build at plot 1, so a build that ignores its origin fails here. The marker is set and restored without neighbour or shape updates. |
| `plotOneMatchesPlotZeroTranslated` | Block-for-block equality site-wide; every `StationBlockEntity` binding matches plot 0 offset. |
| `plotOnePublishesSixtyNineOffsetAnchors` | 69 anchors, bounds offset, `plot_built` line with correlators. |
| `rebuildKeepsPlotTwoPlayerEditsAndLocalPlanFile` | Plot **2** keep + per-plot plan file; `Arrays.equals` on LOCAL plan bytes; edit cell restored in `finally`. |
| `unknownStudioPlotBuildFailedNoPlot` | `IllegalArgumentException`, exact `no_plot` line, no `plot_built`. |
| `wrongOriginPlotBuildFailedBadOrigin` | `STUDIO_A` at plot 2 origin → `bad_origin` with `plot=1`. |
| `misalignedOriginPlotBuildFailed` | x+1 misalignment → `bad_origin`. |
| `unreadablePlanPathPlotBuildFailedIoError` | Plot 3 plan path blocked by a directory → `UncheckedIOException`, `io_error` line, no `plot_built`. |

Every game-test run starts in a fresh world (MP-T worknote, "Game-test environment"), and the tests of one run execute in no guaranteed order. So each test restores `Plots.directory()`, the remote layouts and any block it edited in a `finally`, and no test depends on what another one built: plot 1 is built without `force` by whichever test comes first, plot 2 belongs to the keep test, plot 3 to the `io_error` test and plot 4 to the shell test.
